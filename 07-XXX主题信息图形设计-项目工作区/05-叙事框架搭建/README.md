# 05｜叙事框架搭建

**目标**：从基础数据集中挑选**若干列数据**，组合成明确的叙事主题与阅读顺序，而不是把所有数据同时堆进画面。

## 字段组合范式（用户示例）

几列数据组合后即可形成明确的叙事命题，例如：

| 字段组合 | 形成的叙事主题 | 可能的图形 |
|---|---|---|
| 名称 + GPS（经纬度） | 地图上的地点信息 | 地图标记、地理分布 |
| 名字 + 数值 | 某地 GDP／某类量的比较 | 比较图、排序图、地图 |
| 事件 + 顺序键 + 说明 | 阶段推进或过程 | 流程图、阶段链 |
| 词项 + 词频 | 文本中的关键词突出程度 | 词云（需真实频次） |
| 对象 ID + 类别 ID | 类别成员与分组关系 | 编目清单、矩阵 |

这些是**方法示例**，不代表对本选题的推断，也不意味着字段必须在同一张表内——通过 ID 关联基础表即可，仍保持一格一值。

## 叙事设计要回答

1. 要让读者理解的**核心问题／判断**是什么？
2. 哪几列字段支持这个判断？分别在哪张表、通过什么键关联？
3. 这些字段对应的基础组织逻辑是什么（呼应 02 的 `primary_logic`）？
4. 阅读顺序如何安排——先给结论、按时间推进、按空间展开，还是按类别枚举？
