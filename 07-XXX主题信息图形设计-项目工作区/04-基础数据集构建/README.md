# 04｜基础数据集构建

**目标**：把公共数据、文本文献、图像与自建资料，转换成可检查、可关联、可直接驱动视觉设计的**原子化基础数据集**。

## 核心规则：一格一值

- **一列为一段单一类型的数据**；一行是一个最小记录单位。
- **一个单元格中只能放 1 个数据**——可以是名义数据、量化数据、图像数据或文本文字数据，但**必须只有 1 个**。不把多项内容塞进同一格。
- 字段类型需明确：名义、顺序、数值、时间、文本、图像引用、布尔、ID 等，并写明含义与缺失值规则。
- 不把"姓名＋地点""多个关键词""一组经纬度""金额＋单位"装在同一单元格；多值要拆成多列或建立关联表。
- 图像、长文本可以入表，但一格只对应一项图像引用或一条文本记录；图片本体与规范化引用分别保存。
- 记录 ID、关联键、来源、采集口径、时间范围、可信度与计算方法写入数据字典。
- 无法辨识或缺失的值留空并标记，**严禁为了可视化而猜测**。

## 文件位置

- `基础数据集.csv`：遵循一格一值的规范化数据。
- `数据字典.md`：字段含义、类型、单位、来源与处理规则。

## 转入下一阶段的条件

基础数据集满足"一格一值"，字段类型与来源清楚，可从中挑选若干列组合成叙事。
