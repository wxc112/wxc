# 03｜数据搜集

**目标**：按来源性质分三类收集原始资料，全部可溯源、可核验；暂无法核实的明确标记，不提前混入一个字段。

- [01-公共数据集](./01-公共数据集/)：政府开放数据、机构数据库、公开 CSV/XLSX、API 数据等。记录版本、发布时间、许可与访问日期。
- [02-文本文献](./02-文本文献/)：图书、论文、史料、报告、网页正文、采访等文本资料。记录精确出处、页码／定位、引用权限。
- [03-自建数据集](./03-自建数据集/)：调查、观察、人工编码、图像标注、自采样数据。保留方法、样本口径与采集过程。

## 成果文件（实际开展时新建）

- `数据来源清单.md`：逐条记录资料标识、来源、时间、用途、许可状态、质量与待核实问题。

## 约定

- 本阶段保留原始材料，不改写、不合并。
- 标准化工作留到下一阶段，另建基础数据集，不覆盖来源原件。
- 图片、遥感影像等图像资料连同其来源与授权说明一起保存。

## 转入下一阶段的条件

已收集到足以支撑第 02 阶段叙事方向的核心资料，来源与许可状态清楚，可据此构建基础数据集。
