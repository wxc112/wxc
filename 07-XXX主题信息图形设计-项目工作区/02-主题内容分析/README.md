# 02｜主题内容分析（与大模型协作完成）

**目标**：把选题转化为可搜集数据、可视觉表达的信息问题。**本阶段须与大模型沟通完成**，逐项作出三类判断，并把讨论过程沉淀下来以便复核。

> 判断依据来自 [01-信息图形数据逻辑](../01-信息图形数据逻辑/README.md)（五种基础组织逻辑）与 [02-信息图形类型案例](../02-信息图形类型案例/README.md)（表现形式标签）。**依据主导数据关系判断，不依据外形判断。**

## 第一类判断：基础信息组织逻辑（五选一）

确定主导关系属于哪一种，**只能选一个主归属**：

| 组织逻辑 | 主导数据关系 | 判别要点 |
|---|---|---|
| 编年型 | 阶段／先后／时间演进 | 是否真的存在时间字段与先后依赖？"阶段顺序"不等于"时间轴" |
| 层级型 | 上下位／等级／包含 | 是否存在树状的父子、总分关系？ |
| 编目型 | 类别／成员／清单 | 是否是同类成员的分类罗列，成员间无先后？ |
| 字母表型 | 检索索引／按字母或音序 | 是否以快速检索为主要目的？ |
| 地理图型 | 空间位置／分布 | 是否以地理位置为核心组织键？ |

- 记下 `primary_logic`（唯一主归属）；如有次要逻辑，记为 `secondary_logic` 并说明理由。
- **警惕**：只是"有顺序"不能判为编年型；只是"配了图片"不能判为照片型。要看主导数据关系。

## 第二类判断：表现形式标签（可多选）

从仓库 02 的既有标签中挑选，例如：

- **词云图**——需有真实词频数据支撑，不能只把文字排成云状。
- **文字型／列表型信息图**——以文字与条目为主组织信息。
- **照片型／图片式信息图**——摄影或图片是主要信息载体，而非装饰。
- 混合型、时间轴型、流程图型、比较型、地标型等其余标签。

记下 `primary_tag`（主标签）与 `secondary_tags`（可选），并逐条说明为什么该标签合适、为什么排除其他候选。

## 第三类判断：视觉表现风格（独立选择）

风格与"组织逻辑""表现标签"是**不同维度**，单独判断：

- 平面图形（扁平矢量／几何）
- 照片（写实摄影）
- 插画／手绘
- 拼贴／混合媒介
- 信息排版（以文字版面为主）

记下 `visual_style`。例如可以是"编目型组织逻辑 + 文字型/列表型标签 + 信息排版风格"，三者不冲突。

## 与大模型讨论的输出清单

在对话中逐项确认并写入成果文件：

1. 选题核心命题及拟回答的问题；
2. 主要内容单元、相互关系、是否存在先后或因果依赖；
3. `primary_logic`（唯一）、`primary_tag`、`secondary_tags`（可选）、`visual_style`；
4. 可选用的统计图形、可能的数据字段、关键数据来源与待验证假设；
5. 选择与排除各类型的**理由**——优先记录证据，而不是只给标签。

## 成果文件（与大模型讨论后新建）

- `内容结构.md`：内容单元与相互关系。
- `分类与视觉方案.md`：三类判断的结论与理由。
- `大模型讨论记录.md`：提问、模型回答、采纳／修正的判断依据。

## 转入下一阶段的条件

三类判断均有明确结论与理由，`primary_logic` 唯一；已初步列出需要的数据字段与来源方向，可据此进入数据搜集。
