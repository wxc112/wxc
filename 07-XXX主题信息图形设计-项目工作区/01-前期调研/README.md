# 01｜前期调研

**目标**：明确要做什么选题、为什么做、面向谁、回答什么问题，并摸清资料与数据可得性。

## 要做的事

1. **界定选题**：主题、对象、地域／时期、研究或传播目标、目标受众、设计载体（印刷／屏幕／展陈等）。
2. **提出问题**：这张信息图形要回答的核心问题是什么？读者看完应获得什么判断？
3. **检索已有作品与资料**：收集同类信息图形，分析其内容组织、信息缺口与设计表达，避免重复或踩坑。
4. **登记来源**：逐条记录事实依据、来源 URL、作者／机构、版本、时间、使用权与核验状态。
5. **评估可行性**：区分"已有资料"与"待验证假设"，初步判断数据可得性、工作量与版权风险。

## 成果文件（实际开展时新建）

- `调研记录.md`：调研过程、发现与初步结论。
- `选题问题清单.md`：核心问题与子问题。
- `参考资料清单.md`：来源、URL、作者、版本、许可、核验状态。

## 转入下一阶段的条件

能清楚说明主题、核心问题、初步资料来源与主要受众；已识别关键的数据缺口与待验证假设。
