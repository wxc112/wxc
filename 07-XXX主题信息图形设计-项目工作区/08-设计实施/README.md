# 08｜设计实施

**目标**：把已确认的数据、叙事与视觉编码，实施成可展示、可复核的信息图形作品。

## 工作顺序

1. [01-草图与低保真](./01-草图与低保真/)：纸面草图、线框、信息架构图、初始构图与视觉验证。
2. [02-设计迭代](./02-设计迭代/)：高保真设计、文字／图像／符号精修、适配不同载体、版本记录。
3. [03-最终交付](./03-最终交付/)：最终成品、可编辑源文件（若有）、使用说明、图例与来源说明。

## 最终检查

- 叙事命题是否明确？基础组织逻辑、表现标签与视觉风格是否相互一致？
- 数据是否可溯源，且满足"一格一值"？
- 点线面体、色彩、行距字距、图形、图像与 ISO 符号是否准确表达对应信息？
- 图例、统计口径、单位、地图坐标、标签与文字是否可读？
- 设计表达是否形成独特而统一的视觉系统，避免堆砌无关图形？
- 原图、摄影与引用素材是否满足合法使用和署名要求？

## 约定

不预设具体尺寸、格式、软件或印刷标准，按实际选题确定；实施过程保留可追溯的版本记录。
