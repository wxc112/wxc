# 06｜视觉编码（侧重设计表达）

**目标**：把叙事中选定的字段与信息关系，转换成清楚、准确、有审美完成度的视觉形式。**本阶段偏重设计表达**，不只是挑选现成图表。

## 视觉编码通道

- **点、线、面、体**：位置、方向、长度、面积、体量、形状、密度、明暗与层次。
- **色彩**：色相、饱和度、明度、对比；类别色与连续量色标分开使用。
- **字体与间距**：字体、字号、字重、**行距、字距**、对齐、段落层次与文字节奏。
- **图像与图形**：摄影、照片裁切、插画、拼贴、纹理、图标与符号系统。
- **统计图形**：按 [05-统计图形分析](../../05-统计图形分析/README.md) 确定图表类型、聚合计算、比例尺、图例与单位。
- **ISO 图形／标准化图示**：按 [03-ISOTYPE信息图](../03-ISOTYPE信息图/README.md) 使用可复用的标准符号，保证含义一致。
- **构图表达**：网格、视觉节奏、负空间、视觉锚点、阅读动线、多图层协同与风格一致性。

## 编码审查

按 `数据字段 → 信息含义 → 视觉变量 → 图形形式 → 版式位置 → 校验规则` 逐条记录编码选择：

- 数量不得任意用面积／体积表示，避免夸大或误导；
- 纯装饰元素须标明"不承担数值意义"；
- 编码结果对照 [04-Gestalt视觉组织原则](../../04-Gestalt视觉组织原则/README.md) 检验视觉组织是否合理。
