# 07｜XXX主题信息图形设计·项目工作区

> **实际选题执行区**。与 [06-XXX主题信息图形设计](../06-XXX主题信息图形设计/README.md) 的通用方法模板不同，本文件夹用于**真正做完一个具体选题**：从调研、与大模型协作分析、数据搜集，到基础数据、叙事、视觉编码、测试与交付，逐阶段留下可复核的过程与成果。

> `XXX` 是选题占位符。确定选题后，把本文件夹重命名为真实的主题名称（例如 `07-城市公园使用情况信息图形`），并在各阶段文档中替换 `XXX`。

## 八阶段工作流程

| 阶段 | 工作目的 | 主要成果 |
|---|---|---|
| [01 前期调研](./01-前期调研/README.md) | 明确选题、对象、问题、受众与资料边界 | 调研记录、问题清单、参考资料清单 |
| [02 主题内容分析](./02-主题内容分析/README.md) | **与大模型协作**，判定组织逻辑、表现标签与视觉风格 | 内容结构、分类与视觉方案、大模型讨论记录 |
| [03 数据搜集](./03-数据搜集/README.md) | 分来源收集公共数据集、文本文献、自建数据 | 可溯源、可核验的原始资料 |
| [04 基础数据集构建](./04-基础数据集构建/README.md) | 把原始资料规范化为"一格一值"的原子数据集 | 规范化数据表、数据字典与溯源说明 |
| [05 叙事框架搭建](./05-叙事框架搭建/README.md) | 选择若干列数据组合成明确叙事主题 | 叙事命题、字段组合、信息组织与版式结构 |
| [06 视觉编码](./06-视觉编码/README.md) | 把字段与信息关系转成点线面体、色彩、字体、图形与统计图形 | 视觉编码矩阵、图形符号方案、风格实验 |
| [07 信息轮盘测试](./07-信息轮盘测试/README.md) | 测试方法后续补充，先预留位置 | 待方法明确后补充 |
| [08 设计实施](./08-设计实施/README.md) | 草图、低保真、设计迭代到最终交付 | 草图、迭代版本、成品与说明 |

**主线：** 选题调研 → 与大模型做内容与类型判断 → 三来源数据搜集 → 原子化基础数据 → 字段组合成叙事 → 视觉编码设计 → 信息轮盘测试（待定义）→ 设计实施交付。

## 使用约定

- 每个阶段只记录**真实开展的工作**，不预填虚构的调研结论、数据或成品。
- 所有外部资料必须标注来源、时间、许可与核验状态；无法核实的内容明确标记为待验证假设。
- 阶段之间按 README 中"转入下一阶段的条件"推进，未达标前不跳阶段编造下游成果。
- 与大模型协作的对话要点，沉淀到 `02-主题内容分析/大模型讨论记录.md`，便于复核判断依据。
