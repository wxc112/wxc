# 混合型信息图形｜案例图片与配属文档

本目录专门保存**多组一对一的真实案例图像与其分析**，不要把所有图片堆到一起，也不把整组作品只配一份泛泛说明。

每新增一张作品，建立一个独立目录：

```text
案例/
├── CASE-0001-作品简称/
│   ├── 原图.png
│   ├── 分析.md
│   └── 局部-01.png     # 可选
└── CASE-0002-另一作品/
    ├── 原图.jpg
    └── 分析.md
```

上述是**将来案例格式的示意结构**，不代表已存在这两件作品。图片需是取得并允许存档的用户提供原图，不以虚构图片充数。

在各案例 `分析.md` 中填写五大基础主归属、A 数据逻辑、B 统计和计算、C 点线面体符号色彩视觉编码、D Excel 行列及信息架构、E 视觉叙事；逐图结论回写 [本标签说明](../00-标签说明.md) 和 01 对应基础类型文档。
